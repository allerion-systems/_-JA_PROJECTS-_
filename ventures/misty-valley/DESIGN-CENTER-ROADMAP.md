# Design Center roadmap

*2026-09-06. The committed build order for the configurator suite. One rule
governs everything: retail-priceable kits get full 5D BoM pricing; regulated
or architect-scale builds get honest planning ranges into an intake.*

## Wave 1 — LIVE
Roof Screens · Backyard Studios (sheds) · Decks · Lake Docks (Nolin/Rough/Barren).

## Wave 2 — IN FLIGHT (four builders working)
- Container Designer — 1/2/3 boxes combined, interior footprints, lean-to.
- Barndominium Builder — shop/quarters split, interior BoM.
- Warehouse Designer — PEB shells, dock packages, office corner.
- Modular Projects — hotels/schools/offices/apartments/emergency/government;
  module math + planning ranges → design-build intake. Never a retail price.

## Wave 3 — NEXT: portable commercial buildings
Owner's list, sequenced by fastest honest path to revenue:

1. **Event trailers** — easiest entry: trailer chassis + open service side +
   counters + power. Few code hooks (buyer's event permits are theirs).
   Reuses the container interior machinery on a chassis model.
2. **Mobile bars** — event trailer variant: back bar, taps, cold storage.
   Liquor licensing is the operator's, not ours — one honest line says so.
3. **Coffee shops** — first FOOD-SERVICE unit: health-department plan review,
   NSF surfaces, 3-compartment sink, water/waste tanks. Configurator prices
   the shell + fit-out KIT; the health-code package is a named line item.
4. **Guard shacks** — near-free: MVS-ST-BOOTH already exists; a small
   configurator (size, HVAC, ballistic-rated option, sliding window) rides
   the container designer's bones. GovCon research shows the federal buyer
   (GSA/State replacement market, ~$254K average) — build with the
   Modular-Projects-style range for the rated versions.
5. **Restaurants** — full food-service: hood + fire suppression (NFPA 96),
   grease, ADA. Kit-priceable only at the shell level; kitchen fit-out goes
   planning-range → design-build, same split as Modular Projects.
6. **Fuel / gas stations** — FLAG: this is a fuel-systems product, not a
   building. Dispensers, AST/UST rules, fire marshal, EPA. MVS sells the
   canopy, the kiosk (container/booth machinery) and the C-store shell;
   the fuel skid is a licensed partner's scope, stated plainly. Never imply
   we supply or certify fuel systems.

## Standing rules for every new tool
- Reuse the shared core: bim helpers, PriceBar (guest-gated), Steps/Seg,
  BomTable, QuoteGate, scene lifecycle (lights-once, frameTo, touch rules).
- Every SKU real, unknown SKU throws; hand-check per tool, penny-exact.
- Copy budget ≤3 sentences; compliance line stays; no invented certs.
- Each tool lands in the MCP server next version so agents can drive it.
