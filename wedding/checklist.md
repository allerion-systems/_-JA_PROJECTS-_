# Phased Checklist — 154-Guest Wedding

Work top to bottom; the early phases gate everything else. (Interactive version with saved progress: `index.html`.)

## Phase 0 — Foundations (12+ months out)

- [ ] Set the total budget number and who's contributing what — *before* touring venues
- [ ] Draft the guest list to a real number (154) — headcount drives every other cost
- [ ] Agree on season/date candidates and overall vibe (formal/casual, indoor/outdoor, local/destination)
- [ ] Decide: full planner, day-of coordinator, or trusted-friend point person
- [ ] Tour and book the **venue** (confirm rated capacity is *seated + dance floor* ≥ 160) and lock the date
- [ ] Book the officiant
- [ ] Get engagement photos / decide on them (often bundled with photographer)
- [ ] Start the wedding website (date, city, hotel info — details can come later)

## Phase 1 — Big vendors (8–10 months out)

- [ ] Book photographer (and videographer if wanted) — the good ones go first
- [ ] Book caterer + schedule tasting (if not in-house at venue)
- [ ] Book band or DJ
- [ ] Send save-the-dates (only after venue is contractually locked)
- [ ] Reserve hotel room blocks (2 price tiers, ~40–60 rooms for 154 guests, courtesy blocks if possible)
- [ ] Shop for dress/suit — tailoring lead times run 4–6+ months
- [ ] Choose wedding party and actually ask them
- [ ] Start a master vendor contact + contract + payment-due sheet

## Phase 2 — Design & logistics (5–7 months out)

- [ ] Book florist
- [ ] Book hair/makeup (schedule trial ~2 months out)
- [ ] Order invitations (~85–100 suites + 10–15 extra)
- [ ] Book transportation (couple + shuttles if venue is remote — 154 guests ≈ 2–3 55-seat coach runs)
- [ ] Rentals if needed: tables, chairs, linens, tent contingency priced and hold-dated
- [ ] Book rehearsal dinner venue
- [ ] Plan + book honeymoon (passports current?)
- [ ] Wedding party attire ordered
- [ ] Cake tasting + order (154 servings or display cake + sheet cakes)
- [ ] Register / set up gift plan

## Phase 3 — Lock it down (3–4 months out)

- [ ] Mail invitations (8–10 weeks out; RSVP deadline 4–5 weeks out)
- [ ] Finalize menu + bar package from tasting
- [ ] Buy rings
- [ ] Hair/makeup trial
- [ ] Write vows / choose readings; confirm ceremony structure with officiant
- [ ] Research marriage license requirements (validity window matters — some expire in 60–90 days)
- [ ] Dress/suit fittings round 1
- [ ] Book any welcome-party / morning-after brunch plans
- [ ] Draft the day-of run sheet (`day-of-runsheet.md`)

## Phase 4 — Final approach (4–8 weeks out)

- [ ] RSVP deadline passes → chase stragglers within 48 hours (split the list)
- [ ] Build the seating chart (16–20 tables) — have both families sanity-check for landmines
- [ ] Send final run sheet to every vendor; confirm arrival times in writing
- [ ] Final dress/suit fitting
- [ ] Get the marriage license (inside its validity window)
- [ ] Order/confirm signage, place cards, table numbers, favors
- [ ] Haircuts, final grooming appointments scheduled
- [ ] Confirm shuttle timing against the run sheet
- [ ] Write toasts/thank-yous; nudge scheduled toasters to keep it to 3–5 minutes

## Phase 5 — Week of

- [ ] Give final headcount to caterer (7–14 days out per contract) + vendor meal count
- [ ] Prepare payment + tip envelopes, labeled by vendor
- [ ] Assemble the handoff package for your point person (run sheet, vendor list, envelopes, emergency kit)
- [ ] Delegate: welcome bags dropped at hotels, ceremony items to venue, someone owns gifts/cards at the end of the night
- [ ] Rehearsal + rehearsal dinner (keep the night short)
- [ ] Pack for wedding night / honeymoon
- [ ] Phones charged, chargers in the emergency kit
- [ ] Sleep

## Phase 6 — Day of

- [ ] Eat breakfast
- [ ] Phone off and handed away at hair/makeup
- [ ] Follow the run sheet — or rather, let your point person follow it
- [ ] 5 minutes alone together after the ceremony
- [ ] Eat the meal the caterer held for you
- [ ] One deliberate look around the full room
- [ ] Dance

## Phase 7 — After

- [ ] Return rentals / tux; dress cleaning-preservation if wanted
- [ ] Vendor final payments confirmed cleared; leave reviews for the good ones
- [ ] Send marriage license back / confirm it was filed (officiant usually files — verify)
- [ ] Thank-you notes: within 3 months, batch 10 a night, split between you
- [ ] Name-change paperwork if applicable (SSA → DMV → passport → banks, in that order)
