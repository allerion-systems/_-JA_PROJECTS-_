# Material List — Texas Roadhouse Interior Galvalume Roof Canopy

**Basis:** Field sketch dated 9/1/2026. Canopy face 44'-0" wide × 15'-10" tall (three horizontal courses: 50" + 100" + 40" = 190"). Panel: **5V Crimp**, 24" net coverage — 528" ÷ 22 panels per course works out exactly.

**Scope of this list:** Panel package only (materials supplied by QXO). Framing, blocking, and sheathing behind the panels by others / separate list.

> ⚠️ **Count check:** sketch says "63 total panels" but 22 × 3 courses = **66**. List carries 66. Confirm before ordering.
>
> ⚠️ **Lap allowance:** cut lengths (50"/100"/40") sum exactly to the 190" face height — **zero allowance for course-to-course laps**. If courses lap 3–4" like a real roof, panels must be cut longer or coverage comes up short. If courses butt to a Z-trim line, lengths are fine as drawn. Confirm the detail before releasing the order.
